# 期权权利金年化 · Deribit v1.0

## 安装

1. 如果下载的是 ZIP，先解压。保留整个 deribit-apr 文件夹，不要只打开其中某个文件。
2. 在 Chrome 地址栏输入 chrome://extensions 并回车。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择含 manifest.json 的 deribit-apr 文件夹。
5. 回到交易页面并刷新，点开一个 BTC 期权下单窗口。
6. 数量框下方出现“卖出权利金 · APR”。输入价格、数量即可更新，无需点击卖出。


## 使用

- 未扣费年化：权利金 / 对应本金 × 365 / 剩余天数。
- 扣开仓费年化：（权利金 − 开仓总费用）/ 对应本金 × 365 / 剩余天数。
- 费用优先读取下单框 Fee，仅为页面估算；未读取到时不假设为 0，不显示扣费年化。
- 展开“本金、费用与计算明细”可核对合约、权利金、本金、到期时间，或填写自定义本金和费用。自定义数值的单位是结算币种：BTC 合约用 BTC，BTC_USDC 合约用 USDC。费用为整笔订单总额，不是每份费用。
- “手动修正”停止跟随页面，可自行输入合约代码、BTC 数量、每 BTC 期权价格、报价单位、指数。手动模式需要自行输入费用才能显示扣费年化。
- 点击“恢复自动”会清空自定义本金、费用，恢复足额本金与页面费用。
- 切换合约或重新打开下单框时清空自定义值并恢复自动，避免沿用旧合约数据。
- 页面数量倍增通常不改变 APR；价格、期限、费用比例改变才会改变 APR。
- 暂不支持 IV 报价、市价单、组合订单、ETH 等其他币种。无法唯一识别输入时停止显示年化。
- 支持中文“看涨/看跌”和英文 Call/Put。当前适配站点为 tibired.com、deribit.com 及其子域。

## 本金口径

卖出看涨：对应 BTC 数量作为持币本金；USDC 合约将 BTC 数量按当前指数折为 USDC。

卖出看跌：行权价 × BTC 数量作为美元/USDC 足额名义本金；BTC 本位合约按当前指数折为 BTC。这个口径方便比较权利金回报，币本位看跌的抵押品价值仍会随币价变动，并非无强平保证。

APR 为单利年化，不是复利 APY。到期日按合约日期 08:00 UTC（北京时间 16:00）计算，使用剩余实际秒数 / 86400。USD 和 USDC 的比较按 1:1 名义口径，不处理 USDC 脱锚。

显示的是假设按输入价格卖出开仓的权利金回报，不是实际成交结果、不代表保本收益。未计交割费、平仓费、滑点、资金费用、抵押品币价损益和期权结算损失；实际费用、成交和盈亏以交易所记录为准。买入或卖出平仓不适用此收益解释。

## 权限与数据

Manifest V3 本地插件；只在上述站点加载。没有账户 API、后台服务、联网请求、遥测、存储或自动下单功能。读取可见下单框的合约、指数、数量、报价与费用，插入独立计算卡片。不修改原始交易输入，不点击买入或卖出。

## 验证范围

2026-10-09 已只读核对BTC 下单页面的结构与输入标识；计算和联动在模拟页面中完成测试并查看显示效果，包括报价/数量变化、看涨/看跌、USDC、IV 拒绝及手动修正。尚未在Chrome 中安装后实测；USDC 自动识别仅经过模拟结构测试，实际页面若结构不同会要求手动修正。

首次安装请先核对插件显示的合约、数量、价格、本金与费用，不需要提交订单即可验证。页面改版可能导致自动识别失效，此时用手动模式或更新适配。
